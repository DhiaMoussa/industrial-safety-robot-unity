
# Industrial Safety Robot – Unity & C#

## Présentation du projet

Ce projet, réalisé dans le cadre d'un stage industriel, porte sur le développement d'une simulation 3D d'un robot de sécurité avec Unity et C#.

L'objectif est de reproduire virtuellement le comportement d'un robot chargé de surveiller un environnement industriel et de simuler différents scénarios de sécurité.

## Fonctionnalités développées

- Création d'un environnement industriel virtuel.
- Simulation des déplacements du robot.
- Gestion des états de fonctionnement.
- Simulation d'alertes de sécurité.
- Développement d'une interface utilisateur.

## Technologies utilisées

- Unity
- C#
- Simulation 3D
- Robotique industrielle

## Compétences acquises

Ce projet m'a permis de développer mes compétences en programmation C#, modélisation 3D, simulation de systèmes automatisés et conception de solutions de surveillance industrielle.

## Perspectives d'amélioration

Une évolution possible consiste à intégrer des capteurs connectés et des technologies IoT afin de rapprocher la simulation d'un système de surveillance réel.
